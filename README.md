# Time Bomb Defuser 💣

An interactive countdown game built using HTML, JavaScript, and Tailwind CSS.

## Features

- 10-second countdown timer
- User input for defusing the bomb
- Displays success message when correctly defused
- Displays "BOOM" when the timer reaches zero
- Responsive user interface

## Technologies Used

- HTML5
- JavaScript
- Tailwind CSS

## How It Works

The timer starts at 10 seconds and counts down every second.

To defuse the bomb, enter:

defuse

and press Enter before the countdown reaches zero.
